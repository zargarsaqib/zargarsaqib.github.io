# Personal website — Saqib Ahmad Zargar

A static site with no build step: `index.html` plus the files in `assets/`.

## Deploy on GitHub Pages
1. On GitHub, create a new **public** repository named exactly `zargarsaqib.github.io`.
2. Click **Add file → Upload files**. Upload `index.html`, `README.md` and the `assets/` folder; drag in the whole folder so the structure is kept. Then click **Commit changes**.
3. Go to **Settings → Pages**. Set **Source** to *Deploy from a branch* and **Branch** to `main` / `(root)`, then click **Save**.
4. After 1–2 minutes the site is live at **https://zargarsaqib.github.io**.

## Updating
- Text: edit `index.html` directly on GitHub (pencil icon), then commit.
- CV: replace `assets/Saqib_Zargar_CV.pdf`, keeping the same filename.
- Photo: replace `assets/profile.jpg`, keeping the same filename.
